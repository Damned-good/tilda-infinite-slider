# Tilda Infinite Slider

Кастомный бесконечный слайдер для карточек, собранных в Tilda Zero Block с использованием Auto Layout.

Версия `v0.9.1` является публичной тестовой версией. До завершения тестирования API и поведение могут получать точечные исправления, но архитектура и публичные настройки не должны изменяться без необходимости.

## Возможности

- настоящая бесконечная лента без пустых краёв;
- стрелки «назад» и «вперёд»;
- drag мышью;
- touch swipe;
- autoplay;
- анимация через `requestAnimationFrame`;
- карточки различной ширины;
- поддержка мобильного масштабирования Zero Block;
- защита от повторной инициализации;
- без Swiper, Slick, GSAP и других зависимостей;
- один файл на ES5.

## Требования к Tilda Zero Block

Скрипт ожидает следующую структуру и классы:

| Элемент | Обязательный класс или атрибут |
| --- | --- |
| Zero Block со слайдером | селектор из `SETTINGS.selector` (по умолчанию `.uc-slider1`) |
| Группа-viewport | `.t396__group.container.tn-group` |
| Auto Layout внутри viewport | `.tn-molecule` |
| Каждая карточка — прямой потомок Auto Layout | `.t396__group.slide` |
| Стрелка назад | `.slider-prev` или ссылка `#prev` |
| Стрелка вперёд | `.slider-next` или ссылка `#next` |

Карточки должны располагаться в одну горизонтальную линию. Их ширина может различаться. Промежуток замыкающего перехода вычисляется по реальным промежуткам между исходными карточками.

## Подключение

Добавьте на страницу блок T123 и подключите фиксированную тестовую версию:

```html
<script src="https://cdn.jsdelivr.net/gh/Damned-good/tilda-infinite-slider@v0.9.1/slider.js"></script>
```

Для тестирования текущего состояния ветки `main` можно использовать:

```html
<script src="https://cdn.jsdelivr.net/gh/Damned-good/tilda-infinite-slider@main/slider.js"></script>
```

Для рабочего сайта рекомендуется ссылка с тегом версии, чтобы последующие изменения в `main` не влияли на опубликованную страницу.

После изменения подключения опубликуйте страницу Tilda заново. Файл `slider.js` уже является JavaScript-файлом и не содержит тегов `<script>`.

## Настройки

Настройки находятся в объекте `SETTINGS` в начале `slider.js`:

```js
var SETTINGS = {
    selector: '.uc-slider1',
    autoplay: false,
    autoplayDelay: 4000,
    animationDuration: 750,
    pauseOnHover: true,
    dragEnabled: true,
    dragThreshold: 45,
    dragResistance: 0.35
};
```

| Параметр | Назначение |
| --- | --- |
| `selector` | CSS-селектор всех слайдеров на странице |
| `autoplay` | Включает автоматическое перелистывание |
| `autoplayDelay` | Интервал autoplay в миллисекундах |
| `animationDuration` | Продолжительность перехода в миллисекундах |
| `pauseOnHover` | Приостанавливает autoplay при наведении |
| `dragEnabled` | Включает drag мышью и touch swipe |
| `dragThreshold` | Минимальное расстояние жеста в экранных пикселях |
| `dragResistance` | Сопротивление при протягивании дальше соседней карточки |

Все элементы, найденные по `SETTINGS.selector`, инициализируются как независимые экземпляры. Например, несколько блоков с классом `uc-slider1` будут иметь собственные индекс, очередь анимации, autoplay, drag, resize и состояние бесконечной ленты.

В версии `v0.9.1` объект `SETTINGS` находится внутри замыкания. Чтобы изменить настройки, используйте собственную копию файла или форк репозитория.

## Пример

Минимальный пример структуры находится в [examples/tilda.html](examples/tilda.html).

Для Tilda основная работа выполняется в Zero Block:

1. Создайте горизонтальный Auto Layout с карточками.
2. Добавьте классы `container` для viewport и `slide` для каждой карточки.
3. Добавьте общий класс блока `uc-slider1`.
4. Назначьте стрелкам классы `slider-prev` и `slider-next`.
5. Подключите `slider.js` через T123.
6. Опубликуйте страницу.

## Ограничения

- Скрипт рассчитан на горизонтальную однорядную ленту.
- Клоны карточек полностью неинтерактивны: для них используются `pointer-events: none` и запрет выделения.
- Интерактивные элементы внутри клонированных карточек не поддерживаются.
- Изображения Tilda в клонах принудительно получают `src` из `data-original` или `data-src`, если эти атрибуты существуют.
- Очередь быстрых нажатий на стрелки ограничена тремя переходами.
- Drag нельзя начать до завершения текущей анимации.
- При изменении разметки или классов Tilda селекторы библиотеки могут потребовать адаптации.
- jsDelivr кэширует опубликованные версии; содержимое существующего тега не следует изменять.

## Совместимость

Код написан в синтаксисе ES5 и использует стандартные браузерные API: `querySelector`, `classList`, `requestAnimationFrame`, touch events и `getBoundingClientRect`.

Поддерживаются актуальные версии Chrome, Edge, Firefox и Safari, включая мобильные Safari и Chrome. Internet Explorer не поддерживается.
